Descripción

Sistema de inventario desarrollado en C# para gestionar productos de un almacén.

El sistema permite:

- Registrar productos.
- Buscar productos.
- Eliminar productos.
- Listar productos.
- Consultar productos por categoría.
- Consultar productos agotados.
- Mostrar un resumen del inventario.

Clases principales

- Producto: contiene la información de cada producto.
- Categoria: representa las categorías de los productos.
- Almacen: administra los productos del inventario.
- ReporteInventario: muestra un resumen del inventario.
- Program: contiene el menú principal del sistema.

Instrucciones para ejecutar

1. Clonar el repositorio.
2. Abrir GestionInventario.sln en Microsoft Visual Studio.
3. Ejecutar el proyecto.
